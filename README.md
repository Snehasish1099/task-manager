<!-- To Run the project  -->
### Backend(Node.js)
1. cd backend1
2. npm install
3. node index.js
   or
   index.js


### Backend(Django)

1. cd backend2
2. python -m venv env

3.
# Windows:
env\Scripts\activate
# macOS/Linux:
source env/bin/activate

4.
pip install -r requirements.txt

5.
python manage.py migrate
python manage.py runserver

### Frontend (ReactJs)
1. yarn 
or 
npm install
2. yarn start 
or
npm start
